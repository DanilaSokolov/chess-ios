# Учим Metal

Четыре коротких урока, от треугольника до вычислений на GPU. Каждый урок — один файл
с комментариями на каждом шаге и упражнениями в конце. Шейдеры лежат строкой прямо
в уроке и собираются при запуске, так что всё видно в одном месте.

```bash
cd learn-metal
swift run Lesson1Triangle
swift run Lesson2Board
swift run Lesson3Pawn
swift run -c release Lesson4Compute   # без окна, сохранит mandelbrot.png
swift run Lesson5Pieces
```

Удобнее работать в Xcode: `open Package.swift`, выбрать схему урока и запустить.
Там есть отладчик GPU: во время работы урока **Debug → Capture GPU Workload**
показывает каждую команду кадра, буферы, текстуры и сколько времени занял каждый шейдер.

## Как устроен кадр

```
CPU                                         GPU
───                                         ───
MTLCommandQueue (одна на программу)
  └─ MTLCommandBuffer (один на кадр)
       └─ MTLRenderCommandEncoder
            setRenderPipelineState  ──►  какие шейдеры
            setVertexBuffer/Bytes   ──►  данные
            drawPrimitives          ──►  вершинный шейдер → растеризация → фрагментный шейдер
       commit()  ─────────────────────►  GPU выполняет, пока CPU готовит следующий кадр
```

Дорогие вещи (устройство, очередь, конвейер, буферы с сетками) создаются один раз.
Каждый кадр создаются только буфер команд и кодировщик.

## Как сделаны фигуры

Отдельный разбор с упражнениями: [MODELS.md](MODELS.md) — вершины, нормали,
порядок обхода, тела вращения, выдавливание и как всё это попадает в RealityKit.

## Как это связано с игрой

3D-доска в игре ([Board3DView.swift](../apple/ChessApp/Board3DView.swift)) сделана на RealityKit.
Он сам делает всё, что в уроках пишется вручную: матрицы, глубину, свет, тени,
материалы, анимацию, а нажатие пальца переводит в объект сцены. Под капотом он рисует через Metal.

Писать на Metal напрямую стоит ради своих эффектов (шейдеры в RealityKit — через
`CustomMaterial` и `ShaderGraphMaterial`), своего рендерера или вычислений на GPU.
